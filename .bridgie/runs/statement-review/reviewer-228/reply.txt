T14 passes review: R32 is met and I found only minor issues. I couldn't save the evidence file to the run directory because writing it was denied, so the evidence is the JSON block at the end of this reply.

**What R32 asks and where the code does it**
- **Warning comes first:** `store.new_case` (`src/cma/store.py:443-490`) refuses a root in a git tree, detects the sync folder and gives the warning before anything is made, including the case root itself. The fix in commit 1304c14 is what made this true.
- **Recorded in the case log:** a `sync_folder_warning` entry is written as the log's second entry. If writing it fails, the case folder is removed, so no case is left without its warning.
- **Called from production:** `cma case new` (`src/cma/cli.py:500-515`) is the only caller, and it prints the warning to stderr.
- **Tests:** the runner's own logs show the per-client path tests and the end-to-end command tests ran and passed for all four clients.

**Minor findings**
1. **Symlinked sync folder is missed.** The case root is resolved to its real path, but the Dropbox and OneDrive locations from the config file and environment are not. If `~/Dropbox` is a symlink to `/data/dbx`, a case under it gets no warning.
2. **Two unhandled errors.** A deeply nested Dropbox `info.json` raises a `RecursionError` that isn't caught. `Path.home()` is also unguarded and raises when `HOME` is unset. Either way `cma case new` fails with a raw error instead of making the case.
3. **`claim.json` is wrong in places.**
   - Its list of changed files leaves out `store.py` and `cli.py`.
   - Note (5) says the root is made before the warning, which is no longer true.
   - The 0.17 ms speed figure was never run by the runner, so it is unproven.
4. **Ordinary-named synced folders are missed.** Detection goes by folder name only. On a Mac with iCloud's "Desktop & Documents Folders" option on, a case under `~/Documents` gets no warning. The tests even treat `/Users/ann/Documents/cases` as not synced, and the README's known limits mention this only loosely.
