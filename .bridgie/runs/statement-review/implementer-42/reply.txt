I've built T18. `cma review CASE` now starts a review server that answers only on this machine, and all 46 new tests pass. The full suite passes too (1998 tests), and ruff and compileall are clean.

What the server does:
- **Loopback only:** it listens on 127.0.0.1 and refuses any other address.
- **Token:** each launch makes a new random token and prints the URL with it. A request with a missing or wrong token gets a 403. The token can come in the `?token=` query or an `X-CMA-Token` header.
- **Host check:** the Host header must be exactly `127.0.0.1:<port>`. A missing Host, a repeated one, `localhost`, another port or a rebound name gets a 403, even with a valid token.
- **Bundled assets only:** it serves a fixed list of files shipped in the package (the page, its script and its stylesheet). Any other path, including `..` tricks and full URLs, gets a 404.
- **Strict CSP:** every response carries one that allows scripts and styles only from the server itself, never inline. The page has no inline script or style.
- **No CORS:** the server sends no CORS headers, and a request from another origin is refused.
- **Port:** it takes the next free port from `--port` (default 8765) and says so when none is free.
- **No logging:** the request log is off, so the token never ends up in a log.

The new tests are in `tests/test_review_server.py`. One of them runs `cma review` as a real process, reads the printed URL, and checks it works with the token and is refused without it. I also removed the Host and token checks to make sure their tests fail without them, and they do.

Choices the verifier should know about:
- **No `localhost`:** the Host check accepts only `127.0.0.1:<port>`, to match R33's "the loopback address and port". Opening the page as `localhost` will be refused.
- **No cookie:** browsers share cookies across loopback ports, so the token travels in the asset URLs and in a header instead.
- **GET only:** every other method goes through the same checks and then gets a 405. The override form in T22 will need to add writes.
- **Thin page:** the page shows only the case id and label for now. The case summary, drill-down and writes come in T19 to T22.
