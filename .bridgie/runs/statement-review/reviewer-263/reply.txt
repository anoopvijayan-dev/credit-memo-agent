**Minor finding (`src/cma/synth.py:509`):** the case truth assumes the default pairing window of 3 days. But the case `cma generate --case` makes is paired using the window set in that home folder's `firm.yaml`, which can be anything from 0 to 31 days. With a non-default window, the truth file no longer matches the case the same command made, and nothing records or warns about the mismatch.
- **Repro:** set `own_account_pairing_days: 31`. The £1,000 moves on the 19th of each month then fall within each other's window, so nothing pairs, yet the truth still lists every move as a pair.
- **Smaller windows:** a 7-day window is enough for a nearby supplier direct debit of about £1,000 to break a pair the truth claims.
- **Fix:** generate with the firm's window, or record it in the truth and warn or refuse when it differs.
