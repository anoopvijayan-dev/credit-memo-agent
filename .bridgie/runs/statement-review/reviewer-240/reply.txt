- **Major: the firm's thresholds file can be skipped without warning** (`src/cma/review/summary.py:128`).
  - **What happens:** `case_thresholds()` checks whether the configured path exists. If it doesn't, it quietly uses the packaged thresholds. That includes the case where `firm.yaml` names a firm file under `paths.thresholds`.
  - **Effect:** a misnamed or moved firm file opens the case with the shipped flags and no refusal. The page doesn't show where the thresholds came from, so the underwriter can't tell the firm's file was ignored.
  - **Expected:** `cma run --thresholds` refuses a missing file (`indicators.py:111-112`). The design says no case opens with silently different flags (`design.md:1298`, `1423`).
- **Minor: duplicate indicator ids in multi-account cases.** Indicator ids start again at `I1` for each account. A two-account case gets two `id="indicator-I1"` sections, and a queue entry's `I1` could point to either account's panel.
- **Minor: unproven performance claim.** The 0.53 s timing for 10,000 lines comes from `scratchpad/perf.py`, which no runner tier ran. The queue also isn't paged, although the design calls for paging at 10,000 lines.

Two things I checked and am not reporting:
- The queue doesn't include possible own-account transfers yet. That belongs to the later pairing task, which depends on T43.
