I went through every checklist line for T13. Ruff and compileall pass, and the full suite passes (1868 tests). I made three small fixes:

- **A bug in profile checking:** `vat_stagger` accepted `1.0` and `true` from YAML. It now accepts only the whole numbers 1, 2 or 3, and two new tests cover it.
- **Test marking:** two tests had no `contracts` mark, so the reviewer would not see their results. All 42 tests in `tests/test_case_store.py` now run in the contracts tier.
- **README:** added the `cma case new`, `profile` and `import` commands, and the rule that the case root is owner-only and refused inside a git tree that does not ignore it.

I also added a check that a refused import leaves no work folder behind.

Gaps for the owner, left in `notes` and not changed in code:
1. **Stranded import:** if a save ends "not confirmed" and the entry turns out not to be in the log, importing the same file again says "already imported". This happens because duplicates are detected by the file kept in `inputs/`, not by the log. The import then has no log entry and cannot be redone. This needs a design decision.
2. **Leftover work folder:** a hard crash mid-import can leave a `tmp*` folder in the case folder holding the export. It is owner-only, but nothing cleans it up on the next start.
3. **Inconsistent argument:** `cma case check` takes a folder path, while `new`, `profile` and `import` take a case id.
4. **Clearing lists:** `cma case profile` can replace the directors, shareholders or own accounts from the command line but cannot clear them; only a `--from` file can.
5. **Windows:** owner-only permissions are set with POSIX file modes, which don't change NTFS permissions. The permission tests run only on POSIX.
