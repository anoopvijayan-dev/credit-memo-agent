I fixed all four findings from the failed review of T39. The full suite passes (3032 tests), as do ruff and compileall.

- **Major: names kept whole when a rule matched part of the word.** A word such as GREENFINANCE, BRIGHTPAYROLL or SMITHFINANCE now keeps only the part a rule reads (FINANCE, PAYROLL), and the rest of the word becomes a token. The statement and the profile get the same treatment. The same word gets the same token on every line, and the copy still gives the same figures under v1 and v2.
- **Minor: extra spaces in a name.** "ROSE  BAKERY" (two spaces) and "ROSE BAKERY" now get one token, so M15 no longer splits and the copy is written instead of refused.
- **Minor: wrong thresholds by default.** Without `--thresholds`, `cma pseudonymise` now uses the firm's indicator thresholds, the same ones a case uses. A gambling operator that only the firm lists is no longer replaced by a token.
- **Minor: unproven claims.** I dropped the determinism and speed claims that rested on a script the runner never ran. An existing test already covers determinism, and I make no speed claim.
