T14 is built and committed as 2b54f68: the 37 new tests pass, as does the full suite of 1914.

**What changed:**
- **Detection** (`src/cma/store.py`): a new `sync_folder()` works out whether the case root sits inside one of the four sync clients' folders. It recognises each client by the folder names it uses on Windows, macOS and Linux. It also checks the OneDrive locations Windows records in environment variables and the folders listed in Dropbox's own settings file, so renamed folders are caught too. Symlinks are followed to where the files really land.
- **Creating a case:** `new_case` checks the root before making the case folder. If it is a synced folder, the warning goes to a new `warn` callback, or is raised as a Python warning when no callback is given. It is then saved as the case log's second entry, `sync_folder_warning`, recording the client, the synced folder, the case root and the message.
- **CLI** (`src/cma/cli.py`): `cma case new` prints the warning on stderr before the case is created. stdout still shows only the case id, so anything that reads the id is unaffected.
- **Tests** (`tests/test_sync_folder.py`, all marked `contracts`): sample paths for each client in Windows and macOS/Linux style, plus look-alike names that must not trigger. They also cover the environment-variable and Dropbox-settings cases, a broken Dropbox settings file, the symlink case, and the CLI warning and log entry for each client. Other tests check the warning comes before the case folder exists, that an ordinary folder gives no warning, and that a library caller gets a Python warning.

**Limits worth knowing:**
- This only warns; it never refuses, since R32 asks for a warning only.
- A synced folder whose name no client uses, and that neither the Windows variables nor Dropbox's settings file name, is not detected. A plain folder that happens to be called `Dropbox` or `My Drive` will trigger the warning even if nothing syncs it.
- The log entry stores the case root's path, which can include the computer user's name but never the applicant's.
