I've built the TrueLayer importer (T30, commit `d03a1d9`), and all 2,605 tests pass, along with ruff on `src tests evals` and the compile check.

**What changed:**
- **Same checks as the Open Banking importer.** I moved the second half of the Open Banking importer into a shared function, `openbanking.finish`, and the new TrueLayer importer (`src/cma/importers/truelayer.py`) calls it. Both importers now run the same code for:
  - the £10,000,000,000,000 limit;
  - putting lines oldest first, including lines booked at the same moment;
  - the opening balance, from the running balances or from `--statement-balance` and `--at`;
  - refusing the file if the balance chain breaks anywhere.

  The TrueLayer side reads the file's own fields: it keeps the provider's `transaction_id`, accepts GBP only, checks that the amount's sign matches `transaction_type`, and keeps a transaction once when a page repeats it.
- **`cma case import --format truelayer`** now works. `--statement-balance` and `--at` are accepted for this format too, and the CLI help and README say so.
- **Provider categories are hints only.** TrueLayer's `transaction_category` and `transaction_classification` never touch the statement file. They go into `statements/<account>.hints.json`, and are attached to `Transaction.provider_hint` only after the statement has been read and its figures cached by the statement's bytes. Nothing that computes a figure reads them.

**Tests (`tests/test_import_truelayer.py`, 42 tests):**
- **Golden files:** two hand-written exports in `tests/golden/truelayer/`, one with running balances and one with a statement balance. I checked the expected statements against the balances by hand.
- **Figures unchanged when hints change:** metrics, monthly cells, line categories, indicators and the judgement queue come out identical across five cases:
  - no hints;
  - four different hint sets, including formula, script and prompt-injection text;
  - an unreadable hints file;
  - the same statement imported as a plain CSV.
- **Refusals:** each one names the line and quotes nothing from the file. The Open Banking tests still pass after the refactor.

**Decisions for you:**
- **Pending transactions.** TrueLayer's transactions endpoint returns settled transactions only and has no status field. To meet R36's "booked only", I chose this rule:
  - a transaction with `"status": "pending"` is left out and counted;
  - one with no status, or with settled or booked, is kept;
  - any other status refuses the file.
- **One account per file.** TrueLayer transactions don't carry an account id, so the Open Banking check that refuses a file holding two accounts has no equivalent here.
- **Hints in the record.** The import's case-log entry records a hash of the hints file. The sign-off snapshot doesn't include it, since no figure depends on the hints.
