T29 is done and committed as `a92cec2` on `bridgie-task/statement-review/T29`. `cma case import --format openbanking` now reads OBIE v3.1 transactions files. The 43 new tests pass, the full suite passed (2485), and so did the contracts tier and ruff. The full-suite run started before I added the last two tests; those pass in the 43.

- **Kept lines:** only booked GBP transactions are kept, and the bank's `TransactionId` is the line id.
- **Pending lines:** they are left out, counted in the import message and recorded in the case log.
- **Repeated pages:** a transaction that appears again with identical content is kept once. If it appears again with different content, the file is refused, naming both lines.
- **Balance:** it is rebuilt from the per-line balances, or from a balance the person supplies with `--statement-balance AMOUNT --at DATE`. If both exist they must agree.
- **Refusals:** the file is refused if the balance chain breaks anywhere. Each refusal names the line of the JSON file where that transaction starts and never quotes a field's contents.
- **Tests:** hand-written golden files for both balance routes, plus refusal fixtures for each failure case.

Choices the design left open, all recorded in the claim's notes:
- **Other currencies:** any booked line or balance not in GBP refuses the whole file. The design's failure-modes table says to refuse the account, while R36 says "keep only booked GBP", so I followed the table.
- **Statement balance date:** `--statement-balance` is the closing balance at the end of `--at`. That date must fall between the day before the first transaction and the last transaction.
- **Balance types:** only booked balance types count as per-line balances. An "available" or "expected" balance is ignored, because it can include pending lines or an overdraft limit.
- **Dates and order:** a line's date is the booking date as the bank wrote it, and lines on the same date are ordered by the time booked. Lines booked at exactly the same moment are put in whichever order makes the balance chain work, and refused if no order does.
- **No standalone command:** there is no `cma import openbanking`, because the task asked only for `cma case import`.
