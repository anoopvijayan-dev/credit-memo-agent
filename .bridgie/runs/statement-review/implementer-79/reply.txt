I've built `cma verify` (T38) and committed it as `ba17dcd`. It recomputes every figure, bucket and monthly cell an evidence record holds from the inputs it recorded, and prints each mismatch or "no mismatch". All 2913 tests pass, ruff and compileall are clean, and the offline evals match truth on 9/9 cases.

- **Exit codes:** 0 when nothing differs, 1 when something does, 2 when the record can't be verified.
- **Signed pack records:**
  - Verify first checks that the case still holds the pack's statements, profile and firm rules. If any of these changed, it refuses and names which one.
  - It reads the override log only up to the position the pack recorded, so an override added after sign-off doesn't produce a false mismatch. For this, `overrides.case_figures` got an optional `override_position` argument; leaving it out behaves as before.
  - It finds the case from the id in the record, or from `--case`. It refuses a record checked against a different case.
- **`cma run` records:** verify reads the statement file the record names, also looking for it next to the evidence file, or takes one from `--statement`. It refuses if the file's bytes aren't the ones the record hashed.
- **Another ruleset (R45):** verify refuses before computing anything if the ruleset id is unknown or the installed table hashes differently. The refusal names the record's package version, ruleset id and hash, plus the installed hash. A record made under v1 is checked under v1, whatever `CMA_RULESET` is set to.
- **v0 records (no `schema_version`):** only M1 to M16 are compared, under v1, and the output says that's all it can check.
- **Not compared:** indicators and each line's category. R44 doesn't ask for them; adding them would be simple.

One change outside verify: `cma run`'s evidence record now carries `package_version`, so the R45 refusal can name the version for those records too. It's a new field, which R53 allows. I added the same field to the committed example's evidence, and widened the exact key set in `test_pack_evidence` by that one key. A record written before this change shows up in the refusal as "an unrecorded package version".
