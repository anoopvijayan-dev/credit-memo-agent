Credit Memo

1. Right-click CreditMemo-windows.zip, choose Properties, tick "Unblock" if it is there, then OK.
   (This stops Windows asking about every file inside.)
2. Right-click the zip and choose "Extract All...". Put the folder anywhere you like.
3. Open the folder and double-click "Credit Memo.bat".
   A small window opens and the app opens in your browser.
4. Click "Try with demo data" to see it working, or "New case" for your own statements.

Everything runs on this computer only. Nothing is sent anywhere.
Your cases are kept in %LOCALAPPDATA%\Credit Memo.
Close the small window to stop the app.

Inside: the official Python for Windows from python.org (signed by the Python Software Foundation)
and the Credit Memo code. Source: https://github.com/anoopvijayan-dev/credit-memo-agent
